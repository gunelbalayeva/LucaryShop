# LucaryShop
### Start date: June 7, 2025

LucaryShop is a modular e-commerce iOS application built using MVVM-Coordinator architecture and modern iOS technologies.
## Technologies Used
- UIKit & SnapKit
- MVVM + Coordinator + Builder Pattern
- Combine
- Alamofire / URLSession
- Kingfisher
- API
- MapsKit
- Localization
- Keychain & UserDefaults
- Custom UI Components
- Extensions
- Unit & UI Testing

##  Features
- Authentication (Login, Register, Forgot Password)
- Home, Product, Profile, Cart, Map Screens
- Modular architecture
- Reusable components
- Multilingual support

## Technologies Used

### Navigation
- **UIKit & SnapKit** – For building and laying out the user interface.
- **UIPageViewController** – For implementing swipeable onboarding screens.
- **Custom Animations** – Smooth splash screen animations to enhance UX.
- **Custom Fonts** – Integrated custom fonts for consistent typography.
- **Custom UI Components** – Reusable views and controls to keep UI clean and modular.
- **UI Extensions** – Useful extensions to simplify and enhance UIKit usage.
- **Localization** – Multi-language support (e.g., Azerbaijani, English, Russian).

### Architecture
- **MVVM (Model-View-ViewModel)** – Clean separation of concerns between UI and business logic.
- **Coordinator Pattern** – Handles navigation in a scalable and testable way.
- **Builder Pattern** – Modular and reusable scene construction.

###  Networking
- **Alamofire / URLSession** – For making API requests and handling responses.
- **Combine** – Apple's reactive framework used for data binding and state management.
- **Kingfisher** – Efficient downloading and caching of images from the web.

###  Security & Storage
- **Keychain** – Secure storage for sensitive information like access tokens.
- **UserDefaults** – Lightweight storage for user preferences and settings.

###  Features
- **MapKit** – For displaying and interacting with maps and user location.
- **Splash Screen** – Includes custom animation for the app's launch experience.
- **Page-Based Onboarding** – Swipeable introductory screens for new users.
- **Authentication Flow** – Complete flow for Login, Register, and Forgot Password screens.

### Testing
- **Unit Testing** – To test business logic and view models.
- **UI Testing** – For validating user interface flows and interactions.
